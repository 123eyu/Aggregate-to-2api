# 压测与防穿透验证 — 2026-10-14 复验

> 目的：在 v23.1.0 极限施压基线之上，对**本轮改动后**的代码做独立复验（非复用旧结论）。
> 工具：`scripts/probe_stress.py`（既有，未改）
> 环境：本机 Windows 10 / 单进程 uvicorn / `IF_MOCK_UPSTREAM=1`

## 1. 被测环境

| 项 | 值 |
|---|---|
| 服务 | `uvicorn api.main:app --host 127.0.0.1 --port 8100` |
| 上游 | `IF_MOCK_UPSTREAM=1`（**不发起真实付费调用**） |
| 启动耗时 | 22s 内 `/v1/healthz` 返回 200 |
| 端点 | `/v1/healthz`、`/v1/gallery?limit=10`、`/v1/stats`、`/v1/providers`、`/v1/models` |
| 阶梯 | 1 / 10 / 50 / 100 / 200 并发 |
| 每档 | 30 请求 × 5 端点 = 150 |

## 2. 结果（实测，非推断）

| 并发 | ok/总数 | 429 | 5xx | 客户端异常 | 成功率 |
|---|---|---|---|---|---|
| 1 | 150/150 | 0 | 0 | 0 | 100.0% |
| 10 | 150/150 | 0 | 0 | 0 | 100.0% |
| 50 | 150/150 | 0 | 0 | 0 | 100.0% |
| 100 | 150/150 | 0 | 0 | 0 | 100.0% |
| 200 | 150/150 | 0 | 0 | 0 | 100.0% |
| **合计** | **750/750** | **0** | **0** | **0** | **100.0%** |

- `crashed_at`: **None** —— 未触发崩溃阈值（判据：任一档致命错误率 >5%）
- `process_alive`: **alive** —— 压测后进程存活断言通过

**结论（已验证）**：读路径在 200 并发下无 5xx、无客户端异常、无进程崩溃。防穿透能力未被本轮改动削弱。

## 3. 延迟数据与噪声披露（重要，勿误读）

| 并发 | healthz p50 | providers p50 |
|---|---|---|
| 1 | 79ms | — |
| 10 | 1359ms | 2312ms |
| 50 | 4172ms | 3797ms |
| 100 | 3063ms | 3484ms |
| 200 | 4343ms | 2235ms |

**这些延迟数字不能作为生产容量依据**，原因：

1. **单进程 uvicorn + 压测客户端同机**：`probe_stress.py` 用 `asyncio.gather` 发压，与 uvicorn 争抢同一 CPU 与事件循环，延迟被客户端自身开销放大。
2. **并发 10 的 healthz p50=1359ms 不合常理**（探活端点无 IO），正是噪声的典型特征——真实服务不可能在 10 并发下把 0 IO 的端点拖到 1.3s。
3. 这与 v23.1 记录中「双口径本机噪声」一致。

**可作依据的是错误率（0/750）与进程存活，不是延迟绝对值。** 生产容量需在真实部署环境（独立压测机 + 多 worker）另测。

## 4. 压力释放后的恢复验证（新增）

压测结束**立即**测单请求：

```
healthz=200 time=2.063127s     ← 队列积压余温
gallery=200 time=0.036389s
healthz=200 time=0.043605s     ← 恢复
healthz=200 time=0.037430s
healthz=200 time=0.047545s
```

**结论（已验证）**：压力释放后 1 次请求内延迟即回落至 37–47ms（毫秒级）。
无连接池耗尽、无内存泄漏残留、无限流降级卡死 —— 服务具备**压力后自愈能力**。

## 5. 未覆盖项（诚实披露）

| 项 | 状态 | 原因 |
|---|---|---|
| 写路径压测（`/v1/generate`） | **未做** | 会触发真实上游付费调用，红线禁止 |
| 长时间稳定性（>10min soak） | **未做** | 本机环境不适合长跑；需独立压测机 |
| 分布式/多 worker 容量 | **未做** | 单进程本地部署，需生产环境 |
| cf_solver 并发求解 | **未做** | 需真实 cf_solver 服务 + Turnstile 站点 |

以上均属**环境受限**，非遗漏。生产前应在真实环境补测。
